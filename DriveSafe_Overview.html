DriveSafe - Intelligent Capstone Archival System

A specialized archival platform with AI-powered deduplication and a "Binary Vault" for permanent institutional records.

About

This project is a capstone research that aims to revolutionize academic document preservation through an automated "Binary Vault" strategy. DriveSafe streamlines the transition of capstone projects from student cloud storage to a standardized, teacher-verified institutional repository. The system solves the issue of "link rot" by extracting raw bytes from Google Drive and storing them securely in a centralized database, complemented by TF-IDF semantic analysis for plagiarism detection and version control.

Deployment (Hostinger VPS)

The system is hosted on a Hostinger KVM 1 VPS running Ubuntu. Both the React frontend and Flask backend are served from the same infrastructure using a custom domain ([https://archival-drivesafe.online/](https://archival-drivesafe.online/)).

Setup Process

  1. Server Configuration: Ubuntu 22.04 LTS with Docker and Nginx.
  2. Frontend Build: The React app is compiled via npm run build and served as static files.
  3. Backend Engine: The Flask API handles requests, communicates with MariaDB, and manages Google API streams.
  4. Domain & SSL: Configured via Hostinger's DNS with Let's Encrypt SSL/TLS for secure HTTPS access.

System Access

Note: Access is strictly restricted to Faculty and Registrars. Authentication is handled via Google OAuth 2.0. New accounts are managed through the institutional database to ensure only authorized personnel can access the Archival Ledger and Registry Pipeline.

  • Authorized Access: Use your institutional Google Account (@cit.edu).
  • Database Management: Teacher roles are assigned directly in the MariaDB users table.
